# Teaching material organized by course

Course materials are organized by course and chapter, data are provided as
either an html file or a rendered pdf/odp/pptx presentation.
Please include the source file of the presentations, whenever possible.

Solutions can be uploaded, if needed password-protected. E.g. on mac do: 
`zip -er solutions_default-geco-password.zip solutions.Rmd` and provide the 
default geco password.
